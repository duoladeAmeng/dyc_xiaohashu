## 十、差异分类

每个发现必须归类为以下一种：

### A. 完全等价

代码形式可以不同，但运行行为、并发语义、边界条件一致。

### B. 等价但实现方式不同

例如：

```text
CosId 使用 decorator
目标项目把逻辑写进另一个类
```

只要最终行为一致，就判等价。

### C. 有增强，但不破坏 CosId 语义

例如额外：

```text

日志
metrics
fail-close
```

如果不改变 CosId 正常语义，请明确标记：

```text
增强，可保留，不需要修改。
```

```text

CosId 行为
```
